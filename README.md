# Used Car Price Prediction System

## About the Project
This project predicts the estimated resale price of a used car using Machine Learning.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Flask
- HTML, CSS and JavaScript

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## Dataset
CAR DETAILS FROM CAR DEKHO

## Features
- Car brand and model
- Manufacturing year
- Kilometres driven
- Fuel type
- Seller type
- Transmission
- Previous owner details

## How to Run

Install libraries:
pip install -r requirements.txt

Start backend:
python backend/app.py

Start frontend:
python -m http.server 5500

Open in browser:
http://127.0.0.1:5500/frontend/
